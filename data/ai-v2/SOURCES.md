# Источники обучающих данных QalaFix AI

## TACO — Trash Annotations in Context

- Официальный репозиторий: https://github.com/pedropro/TACO
- Публикация: https://arxiv.org/abs/2003.06975
- Авторы: Pedro F. Proença, Pedro Simões
- Назначение: фотографии мусора в реальной среде — дороги, леса и общественные пространства.
- Использование в QalaFix AI: небольшая воспроизводимая выборка добавляется только в обучающую часть и не входит в validation/final-test.

Точный список изображений и исходных URL сохраняется в `taco-training-sample.json` после запуска `npm run import:taco`.

Остальные изображения набора `ai-v2` созданы специально для этого демонстрационного MVP. Разделение на train/validation/final-test зафиксировано до обучения; фотографии финальной демонстрации в обучающую выборку не добавляются.
