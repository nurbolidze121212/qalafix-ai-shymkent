# QalaFix AI

**Мобильный Smart City MVP для быстрого создания обращений о городских проблемах с помощью локального AI-анализа фотографии.**

Публичная версия: <https://nurbolidze121212.github.io/qalafix-ai-shymkent/>

Главный сценарий проекта — городской мусор: разбросанные отходы, пакеты, переполненный контейнер, крупная куча или стихийная свалка. Фото превращается в готовую заявку, которая появляется на карте и в панели оператора.

## Локальный AI

Модель работает в браузере без платного API. MobileNetV2 создаёт эмбеддинг фотографии, после чего локальный классификатор сравнивает его с несколькими обученными образцами каждого класса:

- `trash`
- `manhole`
- `pothole`
- `water_leak`
- `broken_bench`
- `other`

В QalaFix AI 2.0 используются 140 обучающих изображений, включая 60 мусорных сцен шести подтипов. Данные разделены на 140/30/30 изображений — ровно 70% обучения, 15% validation и 15% независимого финального теста. Текущий слепой тест: 29/30 категорий, 24/25 мусорных сцен, 5/5 чистых сцен и 19/25 подтипов мусора. Четыре дополнительные городские категории проходят отдельную регрессионную проверку 4/4. Подробности публикуются в `data/ai-evaluation.json`. Это результат контролируемого синтетического теста, а не заявленная полевая точность.

Происхождение, лицензии и разделение данных описаны в `data/ai-source/README.md`.

Повторное обучение:

```bash
npm run prepare:ai
npm run train:ai
```

При недоступности модели интерфейс предлагает явно обозначенный демо-режим или ручной выбор. Симуляция никогда не выдаётся за результат локального AI.
