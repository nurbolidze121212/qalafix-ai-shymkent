## Біздің мақсатымыз

**Шымкентті жақсарту үшін қаланы тұрғындардың көзімен көру керек.**

Әр тұрғынның күнделікті кездесетін мәселесін байқап, оны шешуге көмектесу — біздің мақсатымыз.

Мәселе үлкен не кіші деп бөлінбейді. Тұрғын үшін маңызды болса — біз үшін де маңызды.

> **Әр тұрғынның мәселесі — қаланың мәселесі. Біздің мақсат — оны көру, түсіну және шешуге көмектесу.**

## Как это работает

| 1. Добавить фото | 2. Определить место | 3. Проверить обращение | 4. Отправить |
| :---: | :---: | :---: | :---: |
| 📷 Камера или галерея | 📍 Улица и ближайший адрес | ✨ Категория и описание | ✅ Карта и панель оператора |

## Что работает сейчас

| Возможность | Что получает пользователь |
| --- | --- |
| **Камера и галерея** | Можно сделать новый снимок или выбрать готовую фотографию |
| **Определение местоположения** | Приложение находит координаты, улицу и ближайший адрес |
| **Распознавание проблемы** | QalaFix AI предлагает категорию и приоритет обращения |
| **Проверка перед отправкой** | Название, описание, категорию и адрес можно изменить |
| **Карта обращений** | Отправленная проблема появляется на городской карте |
| **Панель оператора** | Оператор видит заявку и меняет её статус |

## Как устроен QalaFix AI

> QalaFix AI обучается понимать городские проблемы по фотографиям: мусор, ямы на дорогах, открытые люки, утечки воды, сломанные скамейки и другие ситуации.

| Техническая часть | Как это работает |
| --- | --- |
| **Основа AI** | TensorFlow.js, мобильная архитектура MobileNetV2 `alpha 0.5` и обученная нейросетевая голова MLP |
| **Обучение** | Каждая фотография превращается в вектор из 1280 признаков, после чего обученный классификатор определяет городскую категорию |
| **Текущие данные** | 176 обучающих фотографий, 30 для проверки во время разработки и 30 отдельных фотографий для финального теста |
| **Результат** | AI определяет категорию, подтип мусора, приоритет и подготавливает текст обращения |
| **Работа на телефоне** | Анализ выполняется локально, без платного AI API и без отправки фотографии во внешний сервис |
| **Контрольная проверка** | 30 из 30 отдельных финальных фотографий, все 5 демонстрационных категорий и 19 из 20 новых реальных фотографий TACO распознаны правильно |

В основе используется официальная модель [MobileNetV2 для TensorFlow.js](https://github.com/tensorflow/tfjs-models/tree/master/mobilenet). Поверх её признаков QalaFix AI обучает собственный сбалансированный MLP-классификатор. Для расширения класса «Мусор» применена отдельная размеченная обучающая выборка из открытого набора [TACO — Trash Annotations in Context](https://github.com/pedropro/TACO). Тестовые фотографии не участвуют в обучении, поэтому модель проверяется на незнакомых изображениях.

Если пользователь исправляет категорию, приложение сохраняет на его устройстве только числовой признак фотографии. Так AI учитывает подтверждённое исправление, но не обучается на собственной ошибке.

### Дальнейшее развитие

С согласия пользователей мы хотим собирать реальные фотографии городских проблем Шымкента, удалять персональные данные и вручную проверять категории. Из этих подтверждённых примеров будет формироваться собственный городской датасет для регулярного переобучения и сравнения новых версий модели. Чем больше качественных и разнообразных фотографий, тем точнее QalaFix AI будет понимать реальные условия города.
